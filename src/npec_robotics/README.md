# npec_robotics

Robotics package for OT-2 simulation and inoculation control.

Depends on npec_cv for vision outputs.

## Public API

```python
from npec_robotics import RoboticsPipeline, PIDRobotController, RLController
```

## Includes

- Gymnasium OT2ENV environment
- PID and RL controllers
- PyBullet simulation wrapper and static assets
- rl_model.zip under artifacts/models
